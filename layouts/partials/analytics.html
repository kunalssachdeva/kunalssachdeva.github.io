{{- /* Two independent, independently-gated analytics beacons. Each emits nothing unless its own key is set, so with both blank - as shipped - the site keeps a zero-third-party-request profile. They are not redundant, they answer different questions: GoatCounter cookieless, stores no IP, keeps full aggregate history. Country-level location, referrers, browser. Free. StatCounter stores the IP and sets a cookie, which is how it can show the per-visitor feed with ISP/organisation and city. The free tier retains only the last 500 pageviews, so it is a live window, not an archive. Running BOTH is a deliberate pairing: StatCounter for the live forensic feed, GoatCounter for the durable long-run trend the free StatCounter tier discards. COMPLIANCE, once StatCounter is enabled: it stores IP addresses and sets a cookie, so EU/UK visitors need a consent notice, and the beacon should not fire before consent. GoatCounter alone needs none. Enabling StatCounter is what creates that obligation - adding GoatCounter alongside does not change it either way. */ -}} {{- with site.Params.analytics.goatcounter }} {{- end }} {{- with site.Params.analytics.statcounter }} {{- if and .project .security }} {{- end }} {{- end -}}
